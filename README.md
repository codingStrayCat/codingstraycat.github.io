# codingstraycat.github.io

Coding Stray Cat 인디 게임 스튜디오의 랜딩 페이지.
**사과게임 · Apple Pop** 의 마케팅 URL + 개인정보처리방침 + AdMob `app-ads.txt` 호스팅.

라이브: https://codingstraycat.github.io/

## 구조

| 파일 | 용도 |
|---|---|
| `index.html` | 메인 랜딩 (vanilla HTML/CSS/JS, 폰 mockup 자동 재생 데모) |
| `privacy.html` | 개인정보처리방침 |
| `app-ads.txt` | AdMob authorized sellers (절대 삭제 금지) |
| `.nojekyll` | GitHub Pages Jekyll 빌드 비활성화 |

## 로컬 미리보기

```bash
python3 -m http.server 9876
open http://localhost:9876/
```
